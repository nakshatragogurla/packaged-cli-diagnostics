# Packaged CLI Diagnostics Tool

A Python command-line tool that inspects a machine and produces a developer-environment health report.

## Features

- Checks Python version
- Checks available disk space
- Checks environment variables
- Detects developer tools
- Generates a human-readable report
- Supports structured JSON output
- Provides useful exit codes
- Designed as an installable Python package

## Requirements

- Python 3.9 or later
